# easy_scripts/ — line-by-line audit of every indicator

Each indicator in the main pipeline (`activity_analysis_STATS_choice_exp.R` +
`analysis_b3.R`) gets its own short R script here. Sources two CSV snapshots
generated by the main pipeline, calls the same `run_lmm_analysis()` / `lmer()`
machinery, prints every step to the console, and saves one PNG per indicator.

No reports. No `.docx`. Just code you can step through line by line in RStudio.

## Quick start

```r
# 1. Generate / refresh the snapshot CSVs (run after any pipeline change)
source("D:/CHOICE R SCRIPTS/choice exp for claude mono and cortisol/claude output/Scripts/analysis_b3.R")
source("D:/CHOICE R SCRIPTS/choice R pipeline/scripts/00_main/run_manu_graphs_only.R")

# 2. In RStudio, open any mini-script and step through with Ctrl+Enter
#    e.g.
file.edit("D:/CHOICE R SCRIPTS/choice R pipeline/easy_scripts/timepoint_aggregated/mean_nnd_cm.R")
```

## What each mini-script does (Steps 1–10)

Every script follows the same 10 steps with explicit `message("Step N — …")`
output so RStudio's console makes the flow obvious:

| Step | What | What you see |
|---|---|---|
| 1 | Load CSV | row × column count |
| 2 | Filter / aggregate to model grain | row count after filter |
| 3 | Apply factor levels | level order |
| 4 | Transformation diagnostics | variance, Shapiro p, N per group |
| 5 | List RE candidates | names of `RE_WIDE`, `RE_WIDE_AGG`, etc. |
| 6 | Fit + AICc-select RE | selected RE, model class |
| 7 | Type-III ANOVA | full ANOVA table |
| 8 | Tukey post hoc + CLD | emmeans, contrasts, compact letter display |
| 9 | Raw summary | mean ± SD per cell |
| 10 | Save graph | PNG to `outputs/graphs/` |

## The two CSV snapshots

Both are **frozen at export time** — mini-scripts never recompute the
derived columns (logit_flow, lr_*, D, D_z, D_y, clr_*).

**`easy_scripts_dataset.csv`** (behaviour, wide, 48 rows = 16 phys-trials × 3
timepoints) carries: trial/phys-trial identifiers, treatment, timepoint(_f/_num),
fish_density(_f), all activity / zone / group-dynamics / Jacobs / CLR columns.
Generated by the inserted block at `activity_analysis_STATS_choice_exp.R`
§5b-bis (line ~2985), after the `PIPELINE_FPS` correction.

**`easy_scripts_endo_dataset.csv`** (endocrine, long, ~1100 rows) carries one
row per (sample × analyte) for cortisol + 7 monoamines × 4 areas. Generated by
the inserted block at the end of `analysis_b3.R`.

## The helper bridge

`_helpers.R` `sys.source()`s the main STATS file with the env-var
`EASY_SCRIPTS_HELPER_LOAD=1` set. A guard at §5 (line ~1758) aborts execution
before model fitting, so the bridge keeps only the helper definitions and
data-prep tables.

If the guard does not fire (e.g. you've edited the STATS file), `_helpers.R`
falls back to a full pipeline run on first source per session (~5–10 min);
subsequent sources within the same RStudio session are no-ops.

Helpers exposed to mini-scripts:
- `run_lmm_analysis()`, `run_betaglmm_analysis()`, `.build_jacobs()`
- `.mg_make_alr_scatter()`, `.mg_make_jacobs_panel()`, `.mg_make_cells_panel()`,
  `.mg_mk_collective_panel()`, `.mg_make_line_with_tukey()`
- `.make_std_plot()`, `.make_indicator_line_plot()`
- `.mg_save()`, `.mg_frame()`, `.mg_treatment_xaxis()`, `.mg_wrap_caption()`
- Theme + palette constants: `BASE_THEME`, `TREATMENT_COLORS_PAL`, `color_map`,
  `TIMEPOINT_LABELS`, `.MG_TAG_THEME`, …

## Regenerating mini-scripts

The 24 behaviour scripts (12 aggregated + 12 by-timepoint) and 7 monoamine
scripts are produced by `_generate_easy_scripts.R` from a template
(`_template_mini_script.R`). Hand-written reference scripts cover the three
families with bespoke logic:

- `timepoint_aggregated/mean_nnd_cm.R` (Gaussian LMM, group dynamics)
- `by_timepoint/logit_flow_main_by_tp.R` (Gaussian LMM, zone preference)
- `endocrine/plasma_cortisol.R` (custom RE candidate set: tank/trial/plate)

To regenerate:

```r
source("D:/CHOICE R SCRIPTS/choice R pipeline/easy_scripts/_generate_easy_scripts.R")
```

Hand-written scripts are NOT overwritten — only files matching the generator's
output filenames are.

## Validation

`_validate.R` (TODO) re-runs each mini-script and diffs:

1. ANOVA tables (`all.equal(tol = 1e-6)` on F / df / p)
2. AICc-selected RE label
3. CLD letter sets
4. Graph PNGs (fuzzy pixel-difference via `magick::image_compare`)

Acceptance: ≥ 100 % pass on (1)–(3); (4) reviewed manually.
